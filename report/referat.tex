\ssr{РЕФЕРАТ}

Расчетно-пояснительная записка к курсовой работе <<Разработка базы данных для видеохостинг-платформы>> содержит \pageref{LastPage}~с., \totalfigures{}~рис., \totaltables{}~табл., 18~ист., 2~прил.

Ключевые слова: БАЗА ДАННЫХ, ВИДЕОХОСТИНГ, МЕДИАКОНТЕНТ, ИНДЕКСИРОВАНИЕ, РЕЛЯЦИОННАЯ МОДЕЛЬ, ОБЪЕКТНОЕ ХРАНИЛИЩЕ, POSTGRESQL, MINIO, REDIS.

Цель работы --- разработка базы данных для хранения и обработки данных видеохостинг-платформы.

Области применения: видеохостинги, образовательные платформы, онлайн-кинотеатры, корпоративные медиатеки и системы управления видеоконтентом.

В ходе выполнения работы проведен анализ предметной области видеохостинга, сформированы требования к функционалу сервиса и данным, определен состав сущностей и связей.
На основе результатов анализа формализована информация, подлежащая хранению, спроектирована реляционная схема базы данных, выполнена проверка отношений на соответствие третьей нормальной форме, разработана ролевая модель доступа.
Реализована спроектированная база данных под управлением СУБД PostgreSQL с интеграцией объектного хранилища MinIO для хранения видеоконтента.
Разработана и внедрена хранимая процедура уведомления подписчиков канала о новом видео.
Проведено исследование влияния стратегий индексирования на время выполнения процедуры массового уведомления подписчиков канала о новом видео в зависимости от количества подписчиков.
